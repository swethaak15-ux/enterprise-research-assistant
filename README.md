Enterprise Research & Report Generation AI Assistant
An AI-powered Enterprise Research Assistant built using Python, LangChain, RAG, Streamlit, and LLMs to automate business research and professional report generation. The system can search the internet and Wikipedia, analyze uploaded PDF/TXT documents, combine information from multiple sources, maintain conversational and persistent memory, and generate structured reports using Pydantic.

The assistant also supports parallel research, sequential report-generation workflows, Python-based data analysis, report downloads, and Gmail integration for sending reports to clients. The entire system is accessible through an interactive Streamlit application.

Key Features
💬 Conversational AI research assistant

🌐 Internet and Wikipedia research

📄 PDF/TXT document research using RAG

🔎 Multi-source information retrieval

🧠 Short-term and persistent memory

🤖 Parallel and sequential agent workflows

📊 Python tool for calculations and data analysis

📝 Structured report generation using Pydantic

📥 TXT/PDF report export

📧 Gmail integration for sending reports

🖥️ Interactive Streamlit interface

🗂️ ChromaDB-based knowledge base

📚 Source references and research history

Tech Stack
Python | LangChain | LangGraph | Streamlit | RAG | ChromaDB | Pydantic | LLMs | Gmail API

The project demonstrates how Agentic AI, RAG, memory, tools, and multi-source research can be combined to build an intelligent enterprise-level research assistant.
